# Oprydningsrobotten

Tag et billede af det, der roder, og en AI-robot laver en plan med én konkret oprydningsopgave ad gangen. Du kan se hvor lang tid det tager, og krydse opgaverne af undervejs.

## Robottens nøgle

Inde i Claude bruger robotten din Claude-konto. På GitHub-siden bruger robotten en gratis nøgle fra Google:

1. Gå til https://aistudio.google.com/apikey og log ind med en Google-konto
2. Tryk Create API key og kopier nøglen. Den starter med AIza
3. Åbn appen, indsæt nøglen og tryk Gem

Nøglen gemmes kun i browseren på den enhed, du bruger. Den ligger ikke i koden her på GitHub. En nøgle fra Anthropic (sk-ant-) virker også.

## Kør siden

Slå GitHub Pages til under Settings, Pages, og vælg branch `main` og mappen `/ (root)`.
